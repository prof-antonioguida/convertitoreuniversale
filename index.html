🔗 scarica da url
Incolla un link diretto a un file video/audio. Per YouTube e altri siti con DRM usa yt-dlp (strumento desktop gratuito) — i browser non possono scaricare da queste piattaforme per limitazioni di sicurezza.
Funziona con link diretti a file .mp4 .webm .mp3 .wav ecc. — non con YouTube, Vimeo, TikTok ecc.

📥 come scaricare da youtube
YouTube blocca i download diretti dal browser. La soluzione più semplice è yt-dlp, uno strumento gratuito e open-source.

1. Installa yt-dlp
pip install yt-dlp oppure scarica da github.com/yt-dlp/yt-dlp

2. Scarica un video
yt-dlp https://youtube.com/watch?v=...

3. Scarica solo l'audio in MP3
yt-dlp -x --audio-format mp3 URL

Poi ricarica il file scaricato qui sopra per convertirlo nel formato desiderato.
